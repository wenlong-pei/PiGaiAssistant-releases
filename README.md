# 皮老板智能阅卷工具 · 发布仓库

本仓库**只存放已发布版本的安装包资产**，不包含任何源码。

- 源码仓库：`wenlong-pei/PiGaiAssistant`（**私有**）
- 自动更新源：本仓库的 Releases（客户端匿名读取）

## 为什么分成两个仓库

GitHub 私有仓库的 Release 对匿名请求一律返回 404，而桌面客户端不携带任何用户
凭据——把 Release 直接放在私有仓库里，自动更新会直接失效。因此拆分为：

- **源码私有** → 评分逻辑、平台选择器、适配器代码不对外暴露
- **发布仓库公开** → 客户端无需任何 token 即可匿名拉取更新包

## 注意

- 本仓库请保持**公开**，改为私有会导致已发布客户端的自动更新立即失效
- Release 资产名遵循 electron-updater 规范：`{name}-setup-{version}.exe` + 同名 `.blockmap` + `latest.yml`
